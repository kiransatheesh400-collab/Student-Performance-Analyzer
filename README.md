# Student-Performance-Analyzer
A mini project built with Numpy. It analyzes the performance of the students by analyzing their marks dataset statistically and displays their grades 

## Features 
 - Creates marks dataset itself randomly
 - Calculates statistics of the given data
 - Calculates performance metrics
 - Display number of students with their grades
## Technologies Used 
 - Numpy
 - Python
## Installation
 Download the student_performance_analyzer.py file in this repo and run it on your python compiler.
## Workflow
 1. Program generates 100 different marks dataset automatically
 2. Calculates Statistics of marks
 3. Calculates performance metrics (average, highest, lowest, etc.)
 4. Displays Grades and analysis to the user

- Statical Analysis
- Data Analysis
