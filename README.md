# Student-Performance-Analyzer
A mini project built with Numpy. It analyzes the performance of the students by analyzing their marks dataset statistically and displays their grades 

## Features 
 - Creates marks dataset itself randomly
 - Does statistics calculation of the given data
 - Display number of students with their grades
 - Analyzes student's performance
## Technologies Used 
 - Numpy
 - Python 3
 - VS Code
